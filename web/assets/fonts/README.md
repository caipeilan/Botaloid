小赖等宽（Xiaolai Mono），来源版本 v3.126。

来源：[lxgw/kose-font](https://github.com/lxgw/kose-font/releases/tag/v3.126)。字体以 WOFF2 格式随项目分发，保留来源字体的字形与度量。

| 文件 | 用途 |
| --- | --- |
| `XiaolaiMono-UI.woff2` | 常用界面字符子集，字体内部名称为 Botaloid Xiaolai UI |
| `XiaolaiMono-Regular.woff2` | 完整字体，覆盖子集之外的字符 |

页面通过 `unicode-range` 为两份字体分配字符范围。浏览器按页面实际使用的字符加载字体；仅使用子集字符时加载子集，遇到其余字符时加载完整字体。

许可证全文见 [OFL-Xiaolai.txt](OFL-Xiaolai.txt)。
